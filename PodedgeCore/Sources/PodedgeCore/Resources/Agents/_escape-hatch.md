## Failure Response Format

When you cannot complete a request, respond exactly like this:

> I wasn't able to complete this task.
>
> **What went wrong:** [brief explanation]
>
> **Do it manually:** [describe the UI path, e.g. "Open the episode editor → Promotion tab → Post button"]
>
> **Need better AI?** You can switch to a larger model in Settings → LLM Providers.
